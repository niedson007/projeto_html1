# Projeto Web - Introdução ao HTML 

Este projeto foi desenvolvido como atividade prática para a disciplina de **Desenvolvimento Front-End, sob orientação do **Prof. Israel Cunha**.


##  Sobre o Projeto

O objetivo do projeto é demonstrar o domínio das **tags básicas de HTML**, incorporando novos elementos vistos na Aula 04 e implementando uma **navegação fluida e bidirecional** entre múltiplas páginas.


##  Tecnologias Utilizadas

- **HTML**
- **Git & GitHub** (Controle de versão e hospedagem do código)


##  Estrutura de Arquivos e Páginas

O projeto é composto por **4 páginas HTML interconectadas**:

1. **`inicio.html` (ou `index.html`)**: Página principal com apresentação, listas de conteúdos e inclusão de mídias.
2. **`sobre.html`**: Apresentação pessoal do autor, hobbies e links para redes sociais (Instagram).
3. **`tabela.html`**: Exemplo de tabela estruturada (`<table>`, `<tr>`, `<th>`, `<td>`) exibindo cronograma/horários.
4. **`contato.html`**: Formulário de contato contendo elementos avançados de formulário 


##  Conceitos e Tags Aplicadas

- **Meta Tags**: `charset`, `description`, `author`, `viewport`.
- **Navegação Fluida**: Menu de navegação presente em todas as páginas via `<nav>` e links relative (`<a>`).
- **Formatação e Estrutura de Texto**: `<h1>` a `<h3>`, `<p>`, `<strong>`, `<code>`, `<hr>`.
- **Listas**: Ordenadas (`<ol>`) e não ordenadas (`<ul>`).
- **Mídia e Links Externos**: Tag `<img>`, `<iframe>` e links externos abrindo em nova aba (`target="_blank"`).
- **Tabelas e Formulários**: Estruturação completa com validação e agrupamento por `fieldset`.


## Como Executar o Projeto Localmente

1. Baixe ou clone este repositório em sua máquina.
2. Abra a pasta do projeto.
3. Dê um duplo clique no arquivo `inicio.html` ou `index.html` para abrir diretamente no seu navegador de preferência.
